# ✅ Version 0.1.0 – Intégration e-mails

Cette version introduit l’envoi d’e-mails personnalisés depuis l’application admin via Firebase Functions et Nodemailer.

---

## 🔧 Fonctionnalités réalisées

- ✅ **Service email intégré**  
  Intégration de `nodemailer` dans une Cloud Function Firebase (hébergée dans `functions/fonctions_mail.js`), déclenchée via `https.onCall`.

- ✅ **Envoi d’e-mail via une action admin**  
  Bouton de test intégré dans le composant `AdminDashboard`, déclenchant un envoi d’e-mail à une adresse de test.

- ✅ **Historique minimal d’envoi**  
  Le champ `lastEmailSentAt` est automatiquement mis à jour dans Firestore (`users/{uid}`) lors d’un envoi d’e-mail.

- ✅ **Gestion des erreurs d’envoi avec affichage utilisateur**  
  Affichage d’alertes claires en cas d’échec ou de succès, pour une meilleure UX (à remplacer par des `Snackbar` plus tard).

- ✅ **Modèles d’e-mail dynamiques**  
  Centralisation des modèles côté **backend** dans `functions/templates/emailTemplates.js` avec gestion de `templateId` et `params`.

---

## 🕗 Fonction non incluse volontairement

- ❌ **Centralisation des modèles dans `app.config.js` (frontend)**  
  Cette étape a été **reportée volontairement**. Le template backend est jugé suffisant à ce stade pour centraliser les modèles d’e-mail, et évite la duplication côté frontend.
